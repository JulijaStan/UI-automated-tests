# Demo Web Shop — UI automated tests

## Overview
Automated UI tests for Demo Web Shop

Features:
- Search, ShoppingCart, Wishlist, Footer, Logo, Login&Registration.

## Prerequisites
- JDK 17
- Maven 3.6+
- Cucumber 7.11.2
- Selenium WebDriver 4.8.0
- Chrome browser installed
- ChromeDriver compatible with your Chrome version
- Internet connection
- IDE (e.g., IntelliJ IDEA, Eclipse) or text editor
- Git (optional, for cloning the repository)
